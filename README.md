# 天鹅输入法

[English](./README.en.md)

天鹅输入法是基于 [Fcitx5 for Android](https://github.com/fcitx5-android/fcitx5-android) 深度定制的一版 Android 输入法。  
当前主程序应用名为 `天鹅输入法`，主程序包名为 `org.fxboomk.fcitx5.android`。

这个分支重点强化了两条能力：

- 剪贴板能力：把本机剪贴板、其他设备剪贴板、图片/文件剪贴板做成了更完整的一套工作流。
- 预测与扩展能力：保留 Fcitx5 的多输入方案体系，同时增强了 RIME 等插件扩展场景。

## 项目特点

### 1. 更强的剪贴板体系

- 主程序剪贴板支持多分类视图：
  - 本机
  - 其他设备
  - 图片文件
  - 全部
- 图片类条目支持缩略图预览。
- URL 条目支持右键菜单直接“打开链接”。
- 图片条目支持右键菜单“查看图片”，调用系统默认程序打开。
- 图片、文件类剪贴板条目会尽量以 URI 形式保留，方便后续发送文件而不是只发送文本。
- 长文本（超过 10 个字符）类型的剪贴板条目支持分词分块展示，便于浏览和二次使用。
- 剪贴板历史记录上限可分别按分类设置。
- 剪贴板分类切换与搜索刷新流程更稳定，减少切换分类或重新打开搜索层时的旧结果残留。

### 2. 剪贴板同步插件

项目已集成 `clipboard-sync` 插件构建链路，可与主程序一起构建和安装。

当前剪贴板同步插件支持：

- [`OneClip`](https://oneclip.cloud/)
- `ClipCascade`
- [`SyncClipboard`](https://github.com/Jeric-X/SyncClipboard)

插件能力包括：

- 自动拉取桌面端剪贴板记录到手机。
- 支持文本、图片、文件等多种剪贴板内容。
- 支持手动上传剪贴板条目到服务端，方便按需同步。
- 支持后台保活、断线重连、前台服务常驻、控制磁贴开关。
- OneClip 支持带访问令牌的拉取、推送、图片和文件下载。
- 文件同步支持保存到指定目录，并尽量保留原始文件名中的中文等 Unicode 字符。
- 支持同步过滤：
  - 文本长度过滤
  - 文件后缀过滤
  - 最大文件大小过滤
- 支持测试连接、测试推送、系统剪贴板授权引导等设置项。
- 近期又补了一轮网络策略限制和 UI 细节修正，使同步状态、权限引导和异常场景反馈更清晰。

如果你的使用场景是“电脑复制，手机输入”或“手机复制，电脑接收”，这一版已经把它当成核心能力来打磨。

### 3. 预测与输入方案扩展

- 保留 Fcitx5 原有的多语言输入方案框架。
- 内置中文输入支持拼音、双拼与五笔；码表类输入法仅内置五笔及其码表。
- 五笔提供独立的设置页，可分组调整上屏方式、候选排序、词库组词、编码提示与按键符号。
- 支持可编辑的自定义双拼方案：独立映射编辑、显式音节覆盖、可重命名，并为每个双拼方案保留独立输入法设置和布局；双拼方案列表不再包含“中文之星”，旧配置会自动迁移到自然码。
- 保留并可加载 RIME 插件，适合自定义方案、词库和高级配置。
- 保留 libime / 中文插件链路中的候选预测、联想与语言模型能力。
- 内置 zh_CN KenLM 已由 4-bit 升级为 8-bit 量化，降低量化误差与预测表条目丢失；`scripts/libime-lm` 提供可复现的模型构建与校验脚本。
- 键盘拉起即用：fcitx 引擎保温运行，切回输入法或退出设置页时不再重复 Rime 初始化与数据同步。
- 输入热路径经过多轮性能优化：减少每次按键的 Binder 往返与冗余候选渲染，并提升 fcitx 线程调度优先级。
- 增强了 [`librime`（中州韵插件）](https://github.com/boomker/librime)的预测能力，可以基于用户输入历史持续学习，并支持预测数据备份。
- 新增和扩展了 AI 预测/问答相关能力，可接入不同模型提供方，并对流式响应、失败回退、请求节流做了专门处理；流式响应会保留增量文本中的单词间空格，避免英文译文粘连。
- 当前 AI 提供方列表已包含 Moonshot 等选项。
- 支持设置模型思考档位（无 / 低 / 中 / 高 / 极致），并在“模型名称与档位”中以模型、档位、可用状态三行展示。
- 悬浮候选窗和候选展开区的操作栏支持人设切换，可选择内置或自定义人设，并立即按新人设重新生成。
- 原“长文”模式已改为“润色”：按当前人设润色光标前文本，点击结果后直接替换原文。
- 问答模式从候选展开区上屏时，会在正文前插入一个换行。
- AI 候选支持独立悬浮窗与候选展开区两种显示方式，可直接浏览更多预测结果。
- 浮动候选窗支持智能定位与光标上方翻转；实体键盘可用数字键选择可见的 AI/计算器候选、用空格提交当前可见的候选或首个预测，方向键高亮后快捷键会作用于高亮项。
- 计算结果会同时出现在横向候选栏和浮动候选窗。
- 虚拟键盘的 AI 预测与原生/Rime 候选统一遵循“预测空格键”行为；实体键盘空格则优先提交当前可见的候选或首个预测。
- 数字键的副字符划动在候选可见时选择对应序号，无候选时仍提交数字；实体键盘在 Rime 中可用方向键切换候选。
- 横向候选栏支持独立调整项目间距与高亮样式，分页时会正确刷新候选内容。
- 输入法重启后会保留手动选择的键盘布局，减少布局被意外切回默认值的情况。
- 候选交互增强：支持上滑选字、下滑重置词频，并在候选区之外提供取消区域；展开候选窗采用更紧凑的自适应网格。长按候选可提交候选串的首字或末字；拆字、重置词频等动作改为长按候选后再上下滑触发，避免普通滑动误触，也把上下滑动让给展开候选窗滚动。
- 键盘层面的可调能力持续增强：MacroKey（含按物理方向的上 / 下滑动宏）、可定制的大写键切换（大写锁定状态在键盘重建、切换布局后保留）、Shift 行为开关、popup 手势滑动选择候选项等。

### 4. 键盘布局与 popup 配置分享

- 新增独立的“键盘布局管理”页：集中管理全部布局（设为默认、上移排序、折叠、增删改、二维码导入分享），布局编辑器则专注内容编辑与实时预览，并可从管理页深链直达；排序与折叠状态会被持久化保存。
- 双拼方案作为“双拼”父布局的子布局管理，支持父节点折叠、子布局继承与首次编辑深拷贝，当前布局链路会显示“布局档案 - 双拼 - 具体方案”。
- 文本键盘布局和 popup 预设支持二维码分享。
- 支持摄像头扫码导入，也支持从文件导入分享数据。
- 分享二维码生成前可直接预览图像内容，方便确认后再发送。
- 文本键盘布局 JSON 支持直接配置按键颜色，便于分享完整的布局视觉方案。
- 文本键盘布局 JSON 支持为不同布局分别设置竖屏和横屏键盘高度。
- Rime 输入方案（子模式）支持单独设置键盘高度，切换方案后立即生效，布局预览同步遵循。
- 键盘高度支持三级覆盖：布局档案 < 基础布局 < 子模式，逐层生效。
- 打开布局编辑器不再切换你正在使用的输入法（改为读取已部署的 Rime schema_list 解析可用方案）；预览 Rime 布局会使用 Rime 引擎自身的身份、空格键标签与图标，预览背景也严格贴合一个键盘高度。
- 键盘布局编辑器支持上移整行，自定义按键的备用字符会保留原始文本。
- 布局管理页会显示当前生效的“布局档案 - 输入法 - Rime 方案”链路，并可按档案过滤未自定义的基础布局；仍有自定义子布局的分组不会被误隐藏。
- MacroKey 支持按物理滑动方向（上 / 下）配置宏动作，并可进一步按输入状态配置动作时机；时机以卡片管理，匹配时优先使用最精确的状态，再回退到“有编码（所有）”和“所有”，显式空动作可阻止回退。按键编辑器仍会自动迁移旧版配置。
- 新增“符号划动映射”，可为半角符号、中文全角形式与 Caps 大写形式分别配置输出；Caps 开启时键面同步显示大写划动符号。
- 符号按键标签会统一转换为 ASCII 等价字符后再送入引擎；提交非 ASCII 自定义符号标签前会先顶字。
- 新增“自动补全成对符号”和“中英字符间插入空格”开关；成对符号支持光标定位与成对退格，实体键盘退格也会触发成对删除，中英空格同时覆盖回车提交预编辑文本的场景。
- 标点符号划动行为可单独配置；按键宽度支持逐键覆盖，并兼容旧版 weight 配置转换，适合制作不等宽的自定义布局。
- 布局编辑器会把 alt/alt1 的真实修改标记为已自定义，方便区分默认值和自定义键位。
- 工具栏和键盘按钮支持配置切换数字键盘的操作。
- 自定义键盘按键可配置大写提示，编辑器会用独立边框标记已修改的按键。
- popup 预设编辑支持恢复默认候选内容，并可继续通过二维码导入导出。
- 布局列表管理与编辑操作分离，管理器专注排序、折叠、增删与深链跳转，自定义布局和宏 popup 预设的刷新更及时。
- 布局配置支持 JSON / ZIP 导入与多配置导出：可从二维码、二维码图片、JSON 文件或 ZIP 压缩包导入，ZIP 可一次导入多套配置；导出时可勾选多套配置并选择二维码、JSON 或 ZIP 格式。

### 5. 工具栏与界面可定制性

- 工具栏按钮支持图标字体和 drawable 两种图标来源，方便统一风格。
- 工具栏按钮图标支持通过 iconfont 字符点位自定义，适合使用统一的图标字体风格。
- 工具栏配置预览支持自定义按钮图标和字体大小，图标会根据主题颜色显示。
- 工具栏高度支持单独配置，候选栏会根据可用空间动态换行，窄屏或大字号布局更容易保持完整显示。
- 主设置页支持搜索，可从搜索结果跳转到跨页面设置项并自动定位、高亮；搜索会索引自定义双拼页面，自动展开折叠分组，打开设置页时搜索框不再自动抢占焦点弹出键盘，点击占位符后才激活。
- “按键与手势”设置重新分组，只保留手势相关项；Rime 方案选择器改为带选中状态的单选列表，并统一标点划动、语言键长按等文案。
- popup 与符号划动映射编辑器使用右下角圆形 FAB 新增条目，长列表最后一项仍可滚动到按钮上方。
- 按键、行、宏等编辑对话框在屏幕旋转后保留未保存内容。
- 布局、按键、字体、popup 等编辑器使用带状态提示的保存图标。
- 输入栏内置更语义化的隐藏键盘图标，界面辨识度更高。
- 状态区在 Rime 引擎下提供默认页与 Rime 页双页签，点击或滑动切页，当前页签高亮显示。
- 输入法选择器、键盘调节浮层、浮动键盘状态保持等界面细节持续优化，主题切换时布局刷新更稳定。
- 新增“工具栏定制”按键，点击直达按钮与图标定制页；KawaiiBar 改用 LinearLayoutManager，按钮等宽且滚动复用后仍保持激活状态。
- 新增键盘高度调整浮层，可拖动实时调整键高，键高调整按钮纳入状态菜单配置。

### 6. 应用内更新与版本获取

- 关于页已内置“检查更新”入口，可直接对比 GitHub Releases 上的最新正式版本。
- 检测到新版本后，会先下载与当前应用包名、设备 ABI 匹配的 APK，再由用户手动点击“安装更新”执行安装。
- 本地构建和 CI 产物的版本段已改成“日期 + 提交短哈希”，更方便定位问题来源。
- 下载应用或插件更新时会显示确定进度，并支持取消当前下载。

### 7. 主题多选切换

- 亮色模式和暗色模式主题支持勾选多个主题。
- 点击明暗切换按钮时，会在当前模式的多个主题间轮询切换。
- 每个模式最多可添加多个主题，方便快速切换不同视觉风格。
- 主题编辑支持更明确的保存、分享和导入操作，主题预览会跟随当前键盘行为更新。
- 主题导入兼容其他 fork 主题 JSON 中的未知字段，第三方主题也能顺利导入。
- 主题预览支持横向主题池轮播；主题列表可直接切换主题池归属，并自动折叠分组，重复卡片和删除后的残留文件也会被清理。
- 内置主题改为只读资产加载，支持资产背景图、模糊半径与背景亮度；复制内置主题会一并复制其背景资产，升级时保留用户自建主题。
- 按钮与图标主题可分别配置：工具栏与按键图标可选用独立的图标主题，主题编辑器支持图标预览与配色调整，运行时窗口会即时刷新。
- 图片主题下的剪贴板搜索改用磨砂底色，主题列表切换选中态时按载荷局部刷新，避免整表重绘。

### 8. 保持 Fcitx5 的插件化结构

- 主程序继续通过插件机制加载额外输入法引擎或功能插件。
- 当前仓库除主程序外，还包含 RIME、Anthy、UniKey、Thai、Hangul、Chewing、Sayura、Jyutping，以及剪贴板过滤/同步等插件与组件。
- 对外部插件安装与联动场景保持兼容。
- JS 插件子系统统一为 plugin + assistant 架构，插件页分为 Fcitx 与 JS 两个标签页；内置 AI Assistant 以 JS 应用插件运行，语音插件支持卸载、覆盖升级与自定义标签。

### 9. JS 插件与 AI 助手

- 内置 AI Assistant 以 JS 应用插件形式运行，通过 JsApp 宿主 API 使用对话框、编辑器、网络请求、面板布局与输入连接能力，并按插件授予网络等权限。
- AI 助手注册为可配置按键（默认不显示）：点击唤起，长按打开服务商、模型与思考档位的快捷设置，或上滑选择“润色 / 翻译 / 问答 / 设置”。
- 新增“简短问答”输出模式，问答结果可在悬浮窗或候选展开区提交；JS 应用支持滑杆、多行输入自适应高度与设置项恢复默认。
- 语音输入支持 AIDL 提供方与 JS 语音插件两种来源，可按首选引擎排序；按住说话松手后会正确结束会话并等待最终识别结果。
- 插件清单可显示内置与导入插件，支持重命名、按 voice 标签归组、卸载内置插件（升级后不再出现）以及导入同名 ID 覆盖升级。

### 10. 符号面板与浮动键盘

- 符号面板重写为 Foxy 风格，支持自备 catalog 与两种布局方式，退格键跟随按键图标主题，并补充韩文字符集与分组顺序调整。
- 工具栏新增符号面板与语音输入快捷操作，语音输入为常规按钮，支持活动图标与按键主题。
- “布局与分体”更名为“分体与浮动”，完整的浮动键盘实现已迁移，可与分体键盘分别配置。
- 浮动键盘、输入法选择器与键盘调节浮层的主题切换与状态保持持续优化。

## 构建

### 依赖

- Android SDK Platform / Build-Tools 36
- Android NDK 28
- CMake 3.31.6
- `extra-cmake-modules`
- `gettext`

当前应用最低支持 Android 7.0（API 24）。

### 初始化仓库

```sh
git clone git@github.com:boomker/fcitx5-android.git
cd fcitx5-android
git submodule update --init --recursive
```

### 本地构建

```sh
./gradlew assembleDebug
```

如果要单独构建剪贴板同步插件：

```sh
./gradlew :plugin:clipboard-sync:assembleRelease
```

如需重建内置中文语言模型，可参考 [`scripts/libime-lm/README.md`](./scripts/libime-lm/README.md)。

构建任务已兼容 Gradle 10 的任务 DSL，并串行化共享 CMake 构建树的 native install 任务，开启配置缓存时更稳定。
