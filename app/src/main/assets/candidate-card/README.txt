Offline character-card data sources

characters.tsv is generated by scripts/build_candidate_card_data.py from:
- Unicode 17.0.0 Unihan.zip (kRSUnicode and kTotalStrokes)
- Unicode 17.0.0 CJKRadicals.txt
- kfcd/chaizi chaizi-jt.txt at e177ab54ce4edf255315a60593ffecbd8167e96b (CC BY 3.0)
- stroke-order.tsv, maintained by Sraw for youmo-ime; the complete cnchar MIT attribution is in that file's header

The chaizi source is redistributed as chaizi-jt.txt under CC BY 3.0. The stroke order source is redistributed as stroke-order.tsv with its upstream MIT notice and project corrections intact. Unihan/CJKRadicals source files are published by Unicode, Inc. under the Unicode Terms of Use.

Pinned source checksums and upstream locations:
- https://www.unicode.org/Public/17.0.0/ucd/Unihan.zip
- https://www.unicode.org/Public/17.0.0/ucd/CJKRadicals.txt (SHA-256 826f83be25cd18fb8a5015a514704504e1982e840ea14d058bf583e1cc620c83)
- https://raw.githubusercontent.com/kfcd/chaizi/e177ab54ce4edf255315a60593ffecbd8167e96b/chaizi-jt.txt (SHA-256 c341a99fc6a4a4f3169279c451ca55057a22603a5d7a520094378f65e817ad26)

To regenerate characters.tsv, download those files and run the generator described by its --help output, passing stroke-order.tsv as --orders.

phrase-pinyin.tsv provides offline phrase readings for the candidate card.
It is generated from mozillazg/phrase-pinyin-data, version 0.20.0, at commit
4afa3226ce53c9138b939e83c3bb294dbe0da511. The upstream MIT notice is included
in phrase-pinyin-LICENSE.txt. Each row has a phrase of 2 to 10 Unicode code
points and one space-separated Pinyin syllable per code point. For duplicate
phrases, the generator keeps the first reading.

Source: https://raw.githubusercontent.com/mozillazg/phrase-pinyin-data/4afa3226ce53c9138b939e83c3bb294dbe0da511/pinyin.txt
Source SHA-256: 5d4d86b1337bb2fca95bc5135564a821bfdb40597481ee3e3871bf52d4668622

To regenerate from the repository root, save the source as pinyin.txt and run
  python3 scripts/build_candidate_pinyin_data.py pinyin.txt app/src/main/assets/candidate-card/phrase-pinyin.tsv
